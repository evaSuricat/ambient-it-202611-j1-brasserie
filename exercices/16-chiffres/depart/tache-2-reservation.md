# Tâche 2 : le formulaire de réservation, cinq minutes

Dans `exercices/16-chiffres/depart/index.html`, dans la section « Venir », après l'adresse, un formulaire `reservation` : nom (texte, obligatoire), date (date, obligatoire), nombre de couverts (nombre, de 1 à 12, obligatoire), bouton « Demander une table ». Chaque champ a son `label`. Pas d'envoi réel : `action="#"`. Styles dans une feuille `exercices/16-chiffres/depart/css/reservation.css` (nouveau fichier), reliée dans `index.html` par une balise `link` : champs sur toute la largeur, bouton dans le style des autres. Règles : celles d'`AGENTS.md`, à la racine du dépôt.

Fini quand : le formulaire s'affiche dans Chrome, F12, console sans erreur, et le navigateur refuse l'envoi d'un champ vide : cliquez le bouton sans rien remplir, une bulle de message apparaît à côté du premier champ.
