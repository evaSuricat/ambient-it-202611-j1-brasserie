# Tâche 2 : le formulaire de réservation, cinq minutes

Dans `index.html`, dans la section « Venir », après l'adresse, un formulaire `reservation` : nom (texte, obligatoire), date (date, obligatoire), nombre de couverts (nombre, de 1 à 12, obligatoire), bouton « Demander une table ». Chaque champ a son `label`. Pas d'envoi réel : `action="#"`. Dans `style.css`, champs sur toute la largeur, bouton dans le style des autres.

Fini quand : le formulaire s'affiche dans Chrome, F12, console sans erreur, et le navigateur refuse l'envoi d'un champ vide (message natif).
