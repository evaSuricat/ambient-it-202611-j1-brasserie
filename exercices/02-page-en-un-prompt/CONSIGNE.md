# E2 · Une page en un prompt

**Point du programme** : le vibe coding. Premier TP de la journée, chronométré.

**Durée** : 15 minutes.

## Ce qu'on fait

1. Ouvrir `depart/` dans Claude Code (panneau VS Code : bouton « + », ou terminal : `claude` depuis le dossier).
2. Lancer le chrono et donner un seul prompt :

   > Lis brief.md. Crée index.html et style.css pour cette page, en respectant les contraintes techniques du brief. Pas de framework, pas de police web, pas de script.

3. Accepter les créations de fichiers. Ouvrir `index.html` dans Chrome (double-clic dans l'explorateur Windows, ou clic droit dans VS Code, « Reveal in File Explorer »).
4. Arrêter le chrono à la première page affichée. Noter le temps dans `chrono.md`.
5. Au plus deux prompts de correction, chacun noté dans `chrono.md` avec son temps.

## Livrable

- `index.html` et `style.css` qui s'ouvrent dans Chrome.
- `chrono.md` : le temps jusqu'au premier rendu, puis le temps de chaque correction.

## Pour aller plus loin

Demander une version qui se lit sur un téléphone (ouvrir Chrome, F12, icône téléphone), ou une version en une seule couleur.

## Si l'outil ne répond pas

La page de `solution/` s'ouvre sans réseau. Le chrono tombe.
